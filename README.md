# Cricket Pressure Performance Dashboard

Interactive analytics dashboard quantifying player performance in high-pressure match situations for T20 and ODI cricket. Built for Rajasthan Royals squad building and player evaluation.

## Features
- **Multiplicative Leverage Index (LI) Framework:** Evaluates pressure across Required Run Rate (RRR), Wickets Remaining, Innings Phase, and Match Closeness.
- **Interactive Visualizations:** Chart.js-powered charts showing pressure distribution, top clutch batters/bowlers, format comparisons, and RRR fit analysis.
- **Clutch Index & Consistency Scoring:** Weighted multi-band scoring isolating true clutch performers from baseline flat-track bullies.

## Live Dashboard / Usage
Open `index.html` in any modern web browser to explore the interactive dashboard.
